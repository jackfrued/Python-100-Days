# Python 百日学练 · Learn & Practice

A Next.js app with two sectors built on top of the **Python-100-Days** lesson notes
(`../Day01-20`):

- **学习 / Learn** — the original course notes, grouped by topic, rendered with a
  lightweight Markdown reader (code blocks, tables, figures).
- **练习 / Practice** — short, AI-generated and **verified** quizzes (7 questions per
  lesson, each set well under 20 minutes). Multiple-choice, predict-the-output, and
  true/false questions with per-question feedback, scoring, and a "review mistakes" pass.

UI is **Chinese by default** with an EN toggle (top-right). All questions and lessons
are bilingual.

## Run

> Requires Node 18.18+. The stack is pinned to Next 14 / React 18 / Tailwind 3 so it
> runs on Node 18 (Next 16 / Tailwind 4 require Node 20).

```bash
cd webapp
npm install
npm run dev      # -> http://localhost:3000
npm run build    # production build (prerenders all 47 pages)
```

`predev` / `prebuild` automatically run `scripts/build-content.mjs`, which:

1. Parses `../Day01-20/*.md` into `src/content/lessons.json` (title, topic, summary,
   reading time, raw markdown).
2. Copies lesson images `../Day01-20/res` → `public/lesson-res` and rewrites paths.
3. `prebuild` also runs `scripts/validate-bank.mjs` to fail the build on a malformed
   question bank.

## Content

- `src/content/lessons.json` — **generated** (gitignored, rebuilt from source).
- `public/lesson-res/` — **generated** (gitignored, copied from source).
- `src/content/questions.json` — **the question bank, committed.** 140 questions
  (20 lessons × 7) generated by a multi-agent workflow and adversarially verified.

### Regenerating / re-verifying the question bank

The bank was produced by a Claude Code workflow: one agent per lesson authors 7
bilingual questions, then each question is adversarially checked for Python-3
correctness (a separate verifier per question; ambiguous/wrong ones are fixed or
dropped). To re-verify locally:

```bash
npm run check:answers   # runs every predict-output snippet through python3
npm run validate:bank   # structural checks (answer keys, dupes, bilingual fields)
```

## Adding more lessons

The data layer already parses any `NN.title.md` in `../Day01-20`. To extend beyond
Day 20, point `scripts/build-content.mjs` at additional `DayNN-NN` folders and add the
corresponding entries to the question-generation workflow.
